# Course brief (compact; full source: docs/curriculum.json)

## Running example — Klopa (story bible)

KLOPA: a fictional student-built app for pre-ordering lunch at a campus canteen (menza). Daily 12:00 lunch rush = natural recurring load spike; 'Ćevap-petak' = Friday flash crowd; 'ispitni rok' = week-long growth. Components (grow over the course): klopa-web (TypeScript frontend built with npm/Vite, served by nginx), klopa-api (Python/Django behind gunicorn with synchronous workers: one request per worker, ≈256 MB per worker – exactly the worker-pool server the M1 sims model, labelled as such; a DeepDive in L02 explains how Node.js/Go/async servers differ), klopa-worker (Python RabbitMQ consumer via pika: kitchen tickets, SMS 'narudžba je spremna'), Postgres, Redis (sessions/cache), RabbitMQ (orders queue), external SMS gateway. Fixed names: domain klopa.example (RFC 2606 reserved – never klopa.hr), registry registry.klopa.example, namespaces klopa and klopa-staging, app port 8000 (gunicorn), web 8080 (unprivileged nginx). Version chain (klopa-api tags): 1.3.2 (v1, blue) → 1.4.0 'vegetarijanski meni' (L13, v2 violet) → 1.5.0 broken (rose, L13) → 1.4.1 small API fix (teal; L14 lab rollout, L15 10 % canary; the version L20 rolls back to; Git still describes 1.4.0 in L16/L22) → 2.0.0 'nova košarica' with a VAT bug: rolled out with RollingUpdate in the L20 hook, rolled back; the L20 sim shows a canary stopping it → 2.0.1 VAT fix shipped through CI + Argo CD (L21–L22) → 2.0.2 hotfix for the Ćevap-petak discount (L24). Cast (fictional, gender-balanced, only in short story beats/speech bubbles – the only place colloquial verbs like 'deployati' are allowed): Lana (backend dev), Davor (ops/on-call; announces Erasmus in L20, is gone by L23 = bus factor), Petra (product, brings requirements), Iva (new teammate from L06/L07, fresh eyes and new mistakes), teta Mira (kitchen, voice of physical consequences: „Dvaput ćevapi?!”). Narrative devices: (1) incident card at the top of each lecture (day/time, symptom, req/s, p95, errors) – every number must be reproducible in that lecture's sim with the preset and seed printed on the card; (2) 'Cijena rješenja' box at the end = next lecture's incident (hook/bridge chain); (3) Klopa karta (src/kit/story/story-map.ts) grows each lecture: 01 users→DNS→laptop/VPS; 02 one VPS resized 2 vCPU/2 GB → 4 vCPU/8 GB + Postgres; 03 second server (srednji), shared DB; 04 load balancer, 3 servers (Mali 1/2, Srednji 2/4, Veliki 4/8); 05 health checks + Redis; 06 RabbitMQ + worker + SMS gateway; 07–09 containers on one Compose host; 10 cluster box; 11 control plane + 3 nodes; 12 Pod; 13 Deployment/ReplicaSet; 14 Service; 15 Gateway; 16 ConfigMap/Secret; 17 node sizes/requests; 18 HPA + Cluster Autoscaler + KEDA on worker; 19 Postgres StatefulSet + PVC (labelled 'u tečaju StatefulSet; u produkciji upravljana baza ili operator'); 20 staging/prod environments; 21 CI + registry; 22 config repo + Argo CD; 23 secret store + ESO; 24 complete + observability. (4) Optional 'Davorov dežurni priručnik' (symptom → cause → command) grows from L11 and is downloadable in L24. Six shared sim engines (pure TS, seeded): E1 Promet (LB/traffic), E2 Red (queue; Kafka only as a DeepDive stepper), E3 Klaster (controllers, scheduler, probes, rollout, HPA/CA), E4 Tvornica (build cache, pipeline), E5 Tko vidi? (secret access graph), E6 Git↔klaster (Argo CD).

## Croatian style guide (AUTHORITATIVE)

Croatian rules for lecture authors (overrides earlier outlines; docs/AUTHORING.md must be aligned – see designRationale). ADDRESS: plural 'vi' (lowercase) for instructions/tasks ('Dodajte poslužitelj…'), inclusive 'mi' for walk-throughs ('Pošaljimo 100 zahtjeva…'); never 'ti'; avoid singular gendered forms. Sim recap label: „Što ste upravo vidjeli”. Buttons/controls: short singular imperative, no full stop ('Pošalji promet', 'Sruši proces'). Objectives are infinitive phrases completing the generated hero 'Nakon ovog predavanja moći ćete…'. STANDARD CROATIAN, IJEKAVICA: točka, tisuća, uvjet, promet (not saobraćaj), računalo, datoteka, operacijski sustav, sigurnost, tko/što, 'je li' (not 'da li'), sljedeći, postupno (not postepeno), postaviti/konfigurirati (not podesiti), trenutačno (currently), omogućuje, ako (not ukoliko), budući da. Use 'podatci' (IHJJ) site-wide. TERMS: poslužitelj in prose ('server' OK in sim UI labels); raspodijeljeni sustav (mention 'distribuirani' once in L03); load balancer (EN); raspodjela opterećenja; kontejner (never spremnik); slika kontejnera (engl. image) – short 'slika' once clear, 'image' only in code/kubectl output, figures are 'prikaz/dijagram/animacija'; pictures of food are 'fotografije' (never 'slike', which collides with container images); čvor (Node only for the API object); klaster; upravljačka ravnina (never 'master'); red poruka; željeno stanje; petlja usklađivanja; provjera živosti/spremnosti/pokretanja for Kubernetes probes; 'provjera ispravnosti' for every other health check (load balancer, Compose healthcheck) – one translation only; 'procesorska jezgra' for CPU cores, 'jezgra (operacijskog sustava)' for the kernel – never bare 'jezgra' where both could be meant; WORKER: in L02/L04/L05 'radnik (engl. worker)' = a server's worker process; in L06+ queue consumers are 'potrošači'; the word 'worker' stays only in the name klopa-worker; `requests`/`limits` in code font with gloss 'zajamčeni minimum / gornja granica' (never translate request as 'zahtjev' – collides with HTTP zahtjev). DEPLOY FAMILY: Deployment = the Kubernetes object (always capitalised); postavljanje (engl. deploy) = the act of getting a version running in an environment; izdanje = release; uvođenje = rollout; isporuka = software delivery in general; kontinuirana isporuka = continuous delivery; kontinuirano postavljanje = continuous deployment. GIT VERBS: in UI and prose say 'spremiti u Git' / 'commit' as a noun (commit/commita/commitovi); never 'commitati/commitaj' outside story speech bubbles. DECLENSION: Kubernetes kinds in PascalCase with endings, no hyphen: Pod/Poda/Podovi/Podova, Deployment/Deploymenta/Deploymenata, Service/Servicea/Serviceu (avoid plural: 'objekti Service'), Secret/Secreta, ConfigMap/ConfigMapa, ReplicaSet/ReplicaSeta, Namespace/Namespacea, Gateway/Gatewaya/Gatewayem, Dockerfile/Dockerfilea, pipeline/pipelinea. Abbreviations with hyphen: RAM-a, CPU-a, API-ja, YAML-a, HPA-a, Argo CD-a. Never decline code: 'naredbom `kubectl apply`', 'agent `kubelet`', 'baza `etcd`'. CODE FONT EVERYWHERE: commands, file names, fields, tags and addresses in hooks, bridges, subtitles and incident cards are written in backticks (`localhost:8000`, `.env`, `latest`, `kubectl apply`, `replicas: 3`, `secret.yaml`); hero and incident card render inline code. First use: hrvatski termin (engl. *term*). TYPOGRAPHY: „…” quotes; decimal comma (0,6 s); space before % and units (50 %, 2 GB); en dash ranges (2–4); sentence-case headings; dates '1. listopada 2026.'; plural counters via Intl.PluralRules('hr'). AVOID MT SMELLS: 'od strane', 'vršiti', 'isti' as pronoun, 'koristeći X', 'na dnevnoj bazi', 'baziran na', 'što da radi', Title Case. FACTS: version numbers only in code blocks or fact callouts with '(stanje: listopad 2026.)'; story text never names a software version. INCIDENT NUMBERS: every number on an incident card or in a hook must be reproducible in that lecture's sim with a stated preset and seed (store the seed on the card); sim cards state the run length. MISCONCEPTIONS: given as a Croatian myth sentence plus an English correction; use the Croatian sentence in MythOrFact and the correction as the explanation. ANALOGIES: always with 'breaks down'. AVOIDED ANALOGIES (never render as Analogy): 'prometni policajac' for a load balancer (L04 – suggests the LB sees the whole road); 'dirigent' for Kubernetes (L10 – shown only as a myth: a conductor runs a script and the music stops with him); 'sef' or 'zapečaćena omotnica' for a Secret (L16 – implies encryption). Tone: friendly, concrete, short sentences, real Klopa numbers, no hype.
